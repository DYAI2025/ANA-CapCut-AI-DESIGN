4. Interface Truthfulness & Backend Boundary Discipline

Prohibition of False Claims
  • No Synthetic Attribution to Real Files: If a user uploads their own file (e.g., clip.mp4), the UI states: "Backend model integration pending. Showing verified synthetic reference analysis."
  • Truthful Capability Reporting: automatedMp4Rendering remains explicitly NOT_IMPLEMENTED.
  • Honest Clipboard Handling: Never displays "Copied" unless the clipboard promise resolves successfully.
  • No Fake Video Rendering: Result screen is labeled "Candidate Edit Preview" with honest EditPilot text instructions.
Local-First Network Audit
  • Google Fonts Fallback: Replaced blocking remote font stylesheet with safe local system font stack (-apple-system, BlinkMacSystemFont, "SF Pro Text") with preconnected optional webfonts.
  • Dev Server Binding: Development server remains bound to local loopback / specified port without telemetry leaks.
  • Zero API Spend: Exactly €0.00 billable API expenditure.
